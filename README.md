# English Coach

An adaptive IT English tutor that runs on your machine. Lessons, answer checks, a vocabulary trainer
with spaced repetition and a structure drill are generated by Claude Code under your own account.
Your progress stays on your computer.

## Install

1. **Claude Code.** Lessons are generated by Claude Code, so it needs a Pro, Max, Team or Enterprise
   plan, or Amazon Bedrock / API access.
   In Terminal: `curl -fsSL https://claude.ai/install.sh | bash`, then open a new terminal, run `claude` once and log in.
2. **The app.** Download `EnglishCoach-macOS.zip` from [Releases](../../releases/latest), unzip it,
   move **English Coach** to Applications and open it. The app is not signed yet, so the first time
   right-click it → **Open** → **Open**. Apple Silicon (M1 and newer) only for now.

The app opens in its own Chrome or Edge window (voice input needs one of them, or Safari).
Closing the window stops it after a couple of minutes. When a new release is out, the home screen
shows **Оновити**: the app downloads it, replaces itself and restarts. Your progress is kept.

Progress is stored in `~/Library/Application Support/English Coach`.

## Run from source

Python 3.9+, no dependencies.

```sh
./start.sh
python3 -m unittest
```

`EC_DATA=/path/to/dir` points the app at another data folder.

## Build

```sh
pip install pyinstaller pillow certifi
python tools/build.py   # dist/English Coach.app
```

Pushing a `v*` tag builds the macOS zip and attaches it to a GitHub release.
